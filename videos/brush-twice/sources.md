# Sources — Why do we brush twice a day?

- NIH News in Health, "Mouth Microbes" — https://newsinhealth.nih.gov/node/3551
  ~700 species of microbes live in the human mouth; some cause disease, others keep harmful ones in check.
- NIDCR, Human Oral Microbiome Database — https://www.nidcr.nih.gov/about-us/timeline/human-oral-microbiome-database
- Streptococcus mutans ferments sugar into (mainly lactic) acid that reaches the enamel through plaque —
  https://bio.libretexts.org/Bookshelves/Microbiology/Microbiology_(Boundless)/15%3A_Diseases/15.07%3A_Bacterial_Diseases_of_the_Mouth/15.7B%3A_Dental_Caries ;
  https://uwaterloo.ca/centre-advanced-science-education/news/critical-ph-and-chatelier-how-everyday-substances-and-habits
- Critical pH ≈ 5.5 for enamel; pH stays below it ~20 min after sugar (Stephan curve, an average) —
  https://www.dentalcare.com/en-us/ce-courses/ce371/glossary ; https://uwaterloo.ca/centre-advanced-science-education/news/critical-ph-and-chatelier-how-everyday-substances-and-habits
- Plaque can start hardening into tartar within 24–72 h; tartar needs professional scaling —
  https://oralb.com/en-us/oral-health/conditions/tartar-and-plaque/plaque-vs-tartar-whats-the-difference ;
  https://www.aspendental.com/dental-care-resources/plaque-vs-tartar/ ; https://hellopearl.com/glossary/dental-calculus
- Brush 2×/day, 2 minutes, fluoride toothpaste (ADA guidance, via dental sources); saliva flow drops sharply in sleep;
  fluoride helps redeposit minerals — https://www.kytdentalservices.com/knowledge-center/oral-hygiene/brushing-twice-a-day ;
  https://biologyinsights.com/is-brushing-your-teeth-once-a-day-enough/
